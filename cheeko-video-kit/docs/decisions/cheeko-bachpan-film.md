**Route chosen:** AI video was priced first (Veo 3.1 element2video 1080p 8 s = 320 credits, Seedance 2.5 10 s 1080p = 3,210), then Ravi asked for a web "puppet show" instead: per shot a 2K base picture + ChatGPT edit variants (mouths eh/aa/oo, blink, gesture), code diffs variant vs base to cut the changed region, mouths driven by voice loudness, camera moves, lighting. Ravi makes the images in ChatGPT from my prompts; refs and samples live in `~/Documents/Cheeko film refs/Scene 1/`. First step = Scene 1 prototype (shots A wide, B Kabir close-up, C Rohan reaction; 12 images).

Scene 5 (birthday) test built from existing hi-res stickers (all 14 V09 stickers now exist hi-res in the Codex folder 01a0e952..., incl. 01:44-01:48 files).
